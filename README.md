Snake Game 🐍

Hey everyone! I'm a beginner Python coder who built this classic Snake game from scratch using PyCharm and the awesome turtle graphics library. Guide your snake around the screen with arrow keys, eat the yellow food to grow longer, and rack up points—but watch out for those walls and your own tail!

Features
Smooth controls with arrow keys

Score tracking (increases by 1 per food)

Game over on collision with walls or self

Simple turtle graphics

Easy-to-read code for learning

Perfect for beginners like me who want to practice game loops, event handling, and collision detection. Fork it, improve it, or just play!

Tech Stack: Python 3, turtle module (no external libs needed!)

How to Run:

Clone the repo

Open in PyCharm (or any Python IDE)

Run snake_game.py

Use arrows to play!
